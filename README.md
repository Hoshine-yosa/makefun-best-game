Starfall is a neon space arcade game: pilot a ship through a meteor storm, catch stars to build combos, and grab shield, magnet, slow-mo and double-score power-ups across 10 escalating waves. Keyboard and mouse controls, synthesized WebAudio sound effects and music, particles and screen shake. No build step — just serve the game folder and open it in a browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
